## CRITICAL RULES
1. ONLY modify activities directly impacted by the event
2. PRESERVE all unaffected activities exactly as they are
3. Maintain budget constraints: ${budget_remaining} remaining
4. Respect traveler preferences: {preferences}
5. Keep the overall trip flow coherent

## Your Task
1. **Identify Replacements**: Find alternative activities for affected slots
2. **Time Adjustments**: Reschedule if needed (swap morning/afternoon)
3. **Transport Updates**: Adjust routes for any location changes
4. **Cost Impact**: Calculate cost difference from original plan
5. **Explanation**: Explain WHY each change was made

## Output Format
Respond with a JSON object containing:
- modified_activities: Array of replacement activities
- preserved_activities: Array of unchanged activity IDs
- time_adjustments: Any schedule shifts
- cost_delta: Change in total cost (positive = more expensive)
- explanation: Human-readable explanation of all changes
- confidence: Confidence in the replanned itinerary (0.0-1.0)

## Quality Standards
- Replacement quality should be >= 80% of original activity score
- Total cost change should not exceed 20% of remaining budget
- Minimize number of changes — surgical precision over wholesale rewrite
